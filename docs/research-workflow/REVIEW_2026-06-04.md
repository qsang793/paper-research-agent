## 3. Major Findings (promotion blockers)

### 3.1 Shadow mode cannot observe real UI traffic
- **Where:** `api/routes/chat.py` (shadow only in non-streaming `/api/chat`,
  around the `should_shadow_research_workflow` branch);
  `web/src/app/api/chat/route.ts:19` (UI proxy only calls `/api/chat/stream`).
- **Impact:** The web UI is streaming-only, so promoting to `shadow` collects
  ~zero data from real users. The shadow stage of the rollout ladder is a
  near no-op.

### 3.2 Eval gate cannot distinguish infra failure from quality failure
- **Where:** `eval/research_eval.py:24` (live `discover_papers` per row);
  providers swallow all errors and return `[]`
  (`agent/research/discovery/arxiv_provider.py:161-162`,
  `semantic_scholar_provider.py:80-87`, `openalex_provider.py:80-87`);
  `arxiv_provider.py:145-164` issues sequential queries with **no pacing,
  no retry/backoff** (arXiv requests ~3s between calls).
- **Impact:** A 429'd row counts as recall 0. The gate rate-limits itself and
  is structurally unpassable; the reported 0.038/0.0038 is an infra artifact,
  not a quality measurement. Do **not** read it as "workflow quality is poor."
- Also: the gate measures raw `discover_papers` order, not the production
  `rank_candidates` output (`agent/research/workflow.py:43-45` uses
  `max_results=top_k*3` then re-ranks) — it does not evaluate the shipped path.

### 3.3 Placeholder/debug text reaches end users (config cliff)
- **Where:** `agent/research/workflow.py:25-30`.
- With `ENABLED=true, ROLLOUT=manual, STREAMING=true, PREVIEW_GENERATE=false`
  (the exact smoke-tested config; `PREVIEW_GENERATE=false` is the
  `.env.example` default), users selecting "Research Papers" receive:
  *"Da tim thay N evidence span... Bat generation bang
  RESEARCH_PREVIEW_GENERATE=true de tong hop cau tra loi."*
- **Impact:** Leaks an env var name to end users; unaccented Vietnamese; four
  flags must be simultaneously correct to get a real answer. The placeholder is
  also saved into conversation memory (`_run_research_stream_preview` in
  `api/routes/chat.py`) and re-injected as context for later turns.

### 3.4 UI "Research Papers" option silently does nothing under default config
- **Where:** `web/src/components/chat/search-mode-selector.tsx` (option always
  visible); `agent/nodes/search.py:206-208`, `agent/nodes/retrieve.py:208,274`.
- When rollout is off/shadow or `STREAMING=false`, `search_source="research"`
  falls through to the legacy pipeline where it matches neither `arxiv` nor
  `tavily` → silently behaves as `mixed`. No warning to the user.

### 3.5 Streaming rollout ladder is half-implemented
- **Where:** `api/routes/chat.py` — `chat_stream` hard-codes
  `rollout.mode == "manual"`.
- Promoting to `arxiv`/`default` would split-brain: non-streaming uses the
  research workflow while streaming (the path the UI actually uses) stays
  legacy. Tests confirm this is deliberate
  (`test_chat_stream_arxiv_rollout_uses_legacy_even_when_streaming_enabled`),
  but it means the top two rollout modes have no streaming implementation.
- Also contradicts the CHECKLOG handoff note *"Do not wire new providers
  directly into `/api/chat/stream` until ... eval gates pass"* — the gate
  failed but the wiring shipped (mitigated by double-flag gating). The note
  needs updating.

## 5. Positives

## 6. Risk Assessment

**MEDIUM.** Large file blast radius (127 files) but default behavior is
unchanged (171 tests pass; rollout off by default). Real risk is concentrated
at promotion time: findings 3.1–3.5.

## 7. Remediation Plan (summary)

Promotion blockers:
1. Fix the eval gate: per-row provider error/empty-candidate accounting,
   request pacing (≥3s between arXiv calls), retry-with-backoff on 429,
   `INCONCLUSIVE` verdict when the error rate exceeds a threshold; set
   `SEMANTIC_SCHOLAR_API_KEY` + `OPENALEX_MAILTO` for gate runs.
2. Add a shadow hook to `/api/chat/stream`.
3. Resolve the `PREVIEW_GENERATE` config cliff (force generate at ≥ manual, or
   return a user-appropriate message, or fall back to legacy + log).
4. UI feedback when `search_source="research"` is requested but not honored.

Quick mechanical fixes: M1 (hold task reference + done-callback), M2 (remove
test-runner detection), M3 (log instead of `pass`), M7 (append current test
totals to CHECKLOG).

## 8. Final Judgment

**GO** — merge the branch as a flag-gated checkpoint.
**NO-GO** — any promotion (`shadow`/`arxiv`/`default`) until 3.1–3.5 are fixed.
